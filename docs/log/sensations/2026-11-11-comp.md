## What was built

| File | What it is |
|---|---|
| `kokopelli/body/components.py` | `Situation`, `Interoception`, `Contact`, and `Senses` to join them. Each has `pre_act(state) -> str` and `update(event)`. `Moment` is the one event; `block(lines)` makes the "Right now:" section |
| `kokopelli/body/master.py` | `resolve(body, action) -> (body, outcome, reason)`. `outcome` is `done`, `refused` or `no_rule` |
| `tests/body/test_components.py`, `tests/body/test_master.py` | 22 and 6 tests |
| `vendor/concordia_patterns/SOURCE.md`, `LICENSE` | Commit, licence, which Concordia idea went to which of our files. No code was copied |

| `kokopelli/body/README.md`, `kokopelli/body/__init__.py` | A row and a line for each new module |

How the pieces fit:

- A **component** is one part of the prompt's body section. Before a decision it's asked for its text (`pre_act`). The
  loop tells it what happened since the last decision with `update`.
- `Interoception` turns the body's numbers into cue lines through `cues.sensations`. It carries both uses: the sweep
  passes `paraphrase` and never sends an event, so `tick` stays `None` and the cue is always shown; the closed loop
  sends `Moment(tick=<decision count>, touched=...)` before each decision, so mild cues come and go as before.
- `Contact` reports what was touched, each thing once, for the one decision after it happened. The body
  (`state.touched`) is still the only place touches collect. `Contact` can take its own table of words, so a scene can
  have touches that aren't in `cues.CONTACT`.
- `Situation` is the scene's who and where. Any scene can make one with its own words.
- `master.resolve` never raises: an allowed action gives the new body, a refused one gives the old body and the
  sentence from `state.CantDoThat`, and an action the body has no rule for (say, wait) gives `no_rule`.

with a small base class, `Component`, whose defaults do real work (feel nothing, ignore events, wrap `lines` in the
header). That is also closer to Concordia's `ContextComponent`, and it removed three copies of the same `pre_act`.

## Decisions for Jayce

Each of these has a choice I made for tonight because it could be undone. None is settled.

1. **Where do touches collect between decisions?**
   - (a) In the body, as now. `state.act` adds to `body.contact`, the loop empties it with `state.touched` and hands the
     list to `Contact` in a `Moment`. `Contact` only holds the current decision's touches. Tonight's choice: `body.jsonl`
     stays the same, and there's one place where touches pile up.
   - (b) In `Contact`, the way Concordia does it: every touch is sent as its own event, the component keeps them and
     empties itself when read. `body.contact` and `state.touched` go away. Cleaner as a pattern, but `body.jsonl`'s
     `contact` field changes, and reading the component twice (the log does) would lose touches unless it's made
     careful.
   - (c) `Contact` reads `state.contact` straight from the body and `update` does nothing. Least code, but then
     "reported once" depends entirely on the caller remembering to clear the body.
2. **Two code paths now make the body block.** `components.py` is what the sweep and the loop use.
   `cues.sensations` (still used by `Interoception` for the body lines) and `cues.block` also still build touch lines
   and the header themselves. A test holds the two equal on 25,920 combinations, so they can't drift unnoticed.
   - (a) Leave it. Costs nothing tonight.
   - (b) Make `cues.py` tables and bands only: drop `contact=` and `block` from it, and move its eight tests onto the
     components. One path, but it edits `cues.py` and `tests/body/test_body.py`, and lane C is about to add pain
     words to the same file.
3. **Should the closed loop go through the game master?** Today `egg_wm.to_sim` catches `CantDoThat` itself. The change
   is four lines and the same behaviour (every verb it handles is in `state.ACTIONS`):

   ```diff
   -from kokopelli.body import components, cues, egg
   +from kokopelli.body import components, cues, egg, master
   ...
   -        try:
   -            self.body = body_state.act(self.body, kind)
   -        except body_state.CantDoThat as refused:
   -            return {"type": "wait"}, str(refused)
   +        self.body, outcome, reason = master.resolve(self.body, kind)
   +        if outcome == master.REFUSED:
   +            return {"type": "wait"}, reason
   ```

   - (a) Apply it after lane A merges. Then the loop has one door to the world's rules. Note the dry runs never hit a
     refusal, so only `test_master.py` covers that path.
   - (b) Leave `to_sim` alone and keep `master.resolve` for new scenes.
   - A related question: "Teo is too far away to hand anything to" is also a refusal by the world, but it needs
     positions from the sim, which `kokopelli.body` may not import. It could stay in the loop, or `resolve` could take
     extra refusal rules from the caller.
4. **How does pain reach the agent?** (lane C will hit this)
   - (a) As a touch, through `Contact` with its own words. Works today. A touch has no bands, so "mild" and "sharp"
     would be two different things touched.
   - (b) As a fourth body variable with bands and wordings like hunger. More faithful, but `state.VARIABLES` feeds
     `drive`, which a test holds equal to the homeostatic experiment's formula. That is another area's code.
5. **One kind of event, or several?** `update` takes a `Moment` (tick and touches). Concordia sends free text. If a
   scene later needs the components to hear something else (the master's outcome, a sound), the options are more
   fields on `Moment` or separate event types that each component picks from.
6. **Outcome names.** `done`, `refused`, `no_rule`. `no_rule` means "not a body action"; `unknown` or `not_mine` would
   also do. Cheap to rename now, before anything calls it.
7. **Coverage as a standing check?** It was measured by hand in a throwaway venv. To make it repeatable, the proposed
   change to `pyproject.toml` (not applied; it's a shared file and it means installing into the shared `.venv`):

   ```diff
    dev = [
   +    "coverage==7.6.10",
        "import-linter==2.16",
        "pytest==9.2.0",
    ]
   ```

   and then the command above with `.venv/bin/python`. Tradeoff: one more dev package and a slower check, against a
   number anyone can reproduce.
8. **A `LICENSE` with no copied code.** `vendor/concordia_patterns/LICENSE` is the Apache 2.0 text, there because the
   plan asks every vendored project to sit with its licence. Nothing of Concordia's is in the repo, so it isn't
   required. Keep it (the terms are next to the note) or remove it (a licence file suggests copied code).
9. **Files outside the lane's list that I edited:** `kokopelli/body/README.md` and `kokopelli/body/__init__.py`, one row
   and one line per new module, because AGENTS.md wants every package's README to say what's in it. Revert at merge
   time if you'd rather the lead did those.
