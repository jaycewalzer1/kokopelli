# P3-E1 Run manifests and golden-run regression (2026-11-09)

Branch `fable/P3-E1`, base `6479b67` (integration/fable after P2-D). CPU only, no model loaded, no GPU job.

## What changed

- **`core/manifest.py` (new).** `manifest(weights=, seed=, prompt=, quantize=, controls=, resolution=, fake=, **extra)` returns
  `commit`, `dirty` (`dirty` bool, `diff_sha256` of `git diff HEAD --binary`, `untracked` count), `weights`, `seed`, `prompt`,
  `quantize`, `controls`, `resolution`, `fake`. Weights: sha256 of every `*.safetensors.index.json` plus `config.json`, and
  the byte size of every `*.safetensors` (stat only, never read; hidden folders such as `.cache/` skipped). `weights` can be
  a dict name → path for runs with several models; `None` entries are dropped, so a fake model has no weights entry at all.
  Git state and weight info are cached per process, because the lunch rewrites `run.json` at start and end.
- **`core/world_transfer_multi.py`**: the sidecar dict gets `"manifest": manifest(...)` (model dir, seed, prompt, quantize,
  per-control path and weight, size, `fake=False`), plus a local import on the line before. Nothing else in the file changed.
- **`city/agents/lunch_parts.py` `LunchRecord.write_sidecar`** (it moved there from `lunch_wm.py` in wave 1): `run.json` and
  every `film/*.mp4.json` get `manifest` with weights `{agent: Qwen path, world_model: models/Cosmos3-Nano-Sim-Transfer}`,
  seeds per agent, WM prompt, quantize, controls, size, and `fake`, `fake_world_model`, `fake_brain`, `brain` (class name).
  A brain that isn't `QwenBrain` counts as fake, and fake models get no weights entry.
- **`tests/test_golden_lunch.py` + `tests/golden/lunch_fake.json` (114 events, 75 KB).** Fixed seed 2025, `FakeWorld`,
  the fake `MultiWorldStream` and `GoldenBrain` (the `ScriptedBrain` from `test_city_lunch` with one change: Iris lets one
  of Mara's lines go unanswered, then Mara asks again). The plain `ScriptedBrain` always answers at once, so the speaker
  never waits and changing `PATIENCE` made no difference to its log (measured: PATIENCE 2→3 gave an identical log). Timing
  fields (`seconds`, `*_s`, `peak_gb`, the `step_time` events) are removed and the run folder becomes `<run>` before the
  comparison. Regenerate with `.venv/bin/python tests/test_golden_lunch.py --update-golden`.
- **`tests/test_manifest.py`**: 8 tests (clean, edited and untracked throwaway repo, a folder that isn't a repo, index
  hash, sizes from a 3 GB sparse file, missing weights, fake labeling).

## Doubts and owner decisions

- **`core/world_stream.py` has no sidecar function.** It's the stdin/stdout worker and writes only `.npy` frames. I left it
  untouched rather than add a new file write. Its runs reach a sidecar through `city/agents/live_wm.py`'s `write_sidecar`,
  which this package doesn't own, so it has no manifest yet. Suggested follow-up: one `manifest(...)` call there.
- The Variant A sidecar line is untested: it sits inside the MLX `run()`, which no CPU test reaches. It uses only names
  the existing sidecar dict already used. The first real or dry-run paint (P3-A's queued dry run) will exercise it.
- `dirty` also counts untracked, non-ignored files, which `diff_sha256` doesn't cover. A run with a new untracked script
  shows `dirty: true, diff_sha256: null, untracked: N`.
- The lunch sidecar's top-level `"model": "Cosmos3-Nano-Sim-Transfer"` still appears on fake runs. `test_city_lunch`
  asserts it, and the field is outside this package's scope. The manifest's `fake: true` and the existing `fake_world_model`
  flag carry the label. The owner may want the top-level field to read "fake" too.
- `P3-A` also edits `world_transfer_multi.py`. My change there is 4 lines inside the sidecar block only.
