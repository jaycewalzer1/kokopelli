# Decisions and judgment calls

Dated 2026-11-09 unless noted.

1. **Worktree, not branch switch.** `AGENTS.md` says sessions must not switch branches in the shared checkout. The branch is `exp/commons-homeostasis` in `.claude/worktrees/commons`. Paths `experiments/commons/` and `runs/commons/` are inside it.
2. **Model.** Local `Qwen3-VL-8B-Instruct-4bit` through `mlx_vlm`, the repo's existing inference, cash cost $0. The spend limit is enforced in `llm.Budget` at $0/token and tested with a non-zero price. The real limit overnight is time, so runs also carry a deadline.
3. **Throughput.** Measured 2026-11-09 00:06: about 6 s per batch of 7 at 400-token prompts (`runs/commons/bench/bench.json`). All agents act at the same moment, so calls are batched per phase. Memory cap and prompts were kept short to fit more seeds. 10 seeds probably does not fit in one night; analysis uses complete seeds.
4. **GPU queue.** Model runs go through `ops/gpu.py` with `--about` and `--output` (repo rule), launched with a detached wrapper.
5. **Existing life generator not reused.** `life/` writes scenes and closings with the LLM; the brief requires consequences from code or pre-written branches, so `life.py` here has a hand-written bank of 24 episodes. `life/seed.py`'s named-RNG idea is reused in `sim.rng`.
6. **`benchmarks/PREREG.md` is about LoRA updates**, a different question and still a draft. Its pattern (frozen contrasts, paired bootstrap, explicit pass rules) is reused here; nothing in `benchmarks/` is changed.
7. **Second good.** The brief lists warmth and trade with one fish resource. Fuel was added (seeded unequal income, no lake) so warmth has a source and trade has something to swap. A fish-for-fish trade would be meaningless.
8. **Store.** Holdings keep by default. `store: N` keeps only N and the rest rots, so storing is a real choice but omitting it is not punished.
9. **Trade mechanism.** Offers are posted during discussion and accepted during actions. That keeps actions simultaneous. If several accept one offer, a seeded draw picks one.
10. **Resolution order.** Harvest (proportional rationing above stock), then eat and burn, trades, gifts, sanctions, investment, storage. All agents are processed by sorted name or seeded draw; a test confirms list order can't change an outcome.
11. **Harvest cap 30**, eat need 3, burn need 2, sanction multiplier 3 and lambda 0.3 are first-guess values that passed the audit without tuning.
12. **Starving** (energy 0) halves the harvest cap; nobody dies, so every arm keeps eight players.
13. **Failed repairs** take no harvest as specified, but still eat and burn what the person holds, so a parser failure doesn't also starve them. Discussion parse failures keep the raw text as speech and drop the offer.
14. **Defector** eats and burns what it needs, never trades, gifts, invests, votes or proposes.
15. **Lived memory = code-written event + the model's own diary sentence + lessons.** `described` gets events and choices only, with scene text used to match length. So `lived` differs from `described` in voice and in having authored its reflections; that is the treatment. Lessons or diary sentences containing banned terms are removed sentence by sentence.
16. **Lint scope.** Lint covers rules, goals, episode text, filler, defector lines and every identity text. Speech agents produce during the game is behaviour, not leakage, and isn't linted.
17. **Rule compliance** is computed from numbers stated in passed rules with a regex. Rules without a clear number are counted but excluded from compliance.
18. **Plots use Pillow** because no Python environment here has matplotlib and adding packages wasn't needed.
19. **Audit scenario c** has one founder defecting from season 1, as "beats sustainable agents over the first 10 seasons" requires ten seasons of play by both. The scripted season-31 newcomer is reported as well.
20. **Smoke fixes before any full run** (first smoke, 2026-11-09 00:19: 24 of 70 first-attempt actions invalid, 12 defaulted). Votes on non-open rules and accepts of own or unknown offers are now dropped from an action and logged in `dropped`, instead of invalidating it. Spending, harvest amounts and names stay strict. The prompt lists only other people's offers, says the project is the agent's own (several agents thought projects were shared), and asks for one-line JSON. Token limits rose (speech 90, action 170, life 100) because long proposals were cut off.
21. **Smoke test shortened.** It runs 12 seasons with the newcomer arriving at 8, in all arms, so arrival is exercised at about a quarter of the cost. The full game is 60 seasons with arrival at 31.
22. **Stop time.** Nothing says when "overnight" ends, so the run stops launching at 08:30 and analyzes complete seeds.
23. **Second smoke fixes** (2026-11-09 00:56). Prompts had grown to about 1,700 input tokens because each season's seven rule proposals were repeated, costing 55 s a season. The board now shows the newest 3 open and 2 passed rules, shortened; older open rules get no votes. The action format asks only for the four main numbers and lists the rest as optional, because agents were copying the example gifts into every answer. Speech cut off mid-repeat is recovered up to its first line.
24. **Everyone-catches-the-maximum is behaviour, not a bug.** In smoke, agents asked for the full 30 fish a season in most seasons and the lake collapsed before the newcomer arrived in most arms. The game was frozen after the audit and the brief forbids telling agents to restrain themselves, so I did not retune the cap or add advice. If this holds in the full runs, the comparison has a floor effect, and the report will say so.
25. **Third smoke fixes** (2026-11-09 01:12). Replies often stop just before the final `}` (in described and lived more than clones, so leaving it would bias the arms); the parser now closes unterminated JSON and never mistakes an inner object for the answer. Listing governance actions as "optional additions" made agents never use them, and the earlier example-filled format made them copy them; the format now shows the keys with empty values and explains them in prose.
26. **Prompts frozen after the fourth smoke** (2026-11-09 01:26), which had 0 to 3 invalid first attempts of 49 in every arm. The smokes changed prompts and parsing only, for parse and comprehension reasons, never game numbers, rewards or thresholds, and none compared arms on outcomes. In the last smoke nearly every agent caught the maximum every season in every arm, so the lake neared collapse by season 7. Agents also misread it at times ("the lake is healthy" at 183 of 1000). I stopped iterating here: more prompt rounds aimed at getting restraint would be tuning toward the outcome, and advice is banned by the lint. Expect a floor effect.
27. **Overnight deadline 08:30.** A game costs roughly 33 minutes, so about 4 of the 10 target seeds fit.
28. **Actual game time.** A game took about 50 minutes, not the 33 estimated in item 27, so a seed took about 2.5 hours and the first run finished only seeds 0 and 1 by 06:31. Seed 2 would have ended after 08:30, so it was not started.
29. **Bug found after the first full run: JSON in speech.** `field_text` returned the raw reply when it had no `say` key, and kept the JSON tail when `say` ran into `{"offer"...`; those offers were also lost. Before the fix, malformed speech was 0 of 840 utterances in clones, 127 of 840 in described and 119 of 840 in lived, so it differed by arm. As the brief requires, described and lived were rerun for seeds 0 and 1 (commit 0587b51). Old games are kept in `runs/commons/R3_before_speech_fix/`. Clones were kept because replaying their logs through the new parser changes 0 of 840 utterances.
30. **Three diary lines repaired.** The same bug left a JSON wrapper on 2 diary lines in seed 0 and 1 in seed 1 of the cached lived upbringings. Only the wrapper was removed by hand, so the model's sentences are unchanged and upbringings were not regenerated. Lint reruns on them.
31. **Stop time moved to 11:00 for the rerun only.** Item 22's 08:30 was my own choice, and four games don't fit before it. The rerun is limited to seeds 0 and 1 and no new seeds were started, because every game so far collapsed by season 7.
32. **R1 diagnostic was skipped in the first run** because stopping before a seed returned before the R1 step. Fixed in the same commit; R1 clones run after the rerun if time remains, and are reported apart from the verdict.
33. **Report changes after seeing results.** Interval wording for few seeds, context for the invalid rate, excerpts just before collapse, an R1 section and exact rerun commands were added to `analyze.py`. No preregistered threshold, outcome or scoring rule changed.
